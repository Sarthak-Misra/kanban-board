# Kanban Board

A responsive and interactive Kanban Board application built with HTML, CSS, and JavaScript. Organize tasks efficiently by creating, managing, and moving tasks across different workflow stages. Inspired by the Kanban methodology for visual task management.

## Live Demo

🔗 https://kanban-board-hazel-tau.vercel.app/

## Features

* Create new tasks
* Edit existing tasks
* Delete tasks
* Drag and drop tasks between columns
* Organize work using Kanban workflow stages
* Responsive and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Sarthak-Misra/kanban-board.git
```

2. Navigate to the project directory:

```bash
cd kanban-board
```

3. Open `index.html` in your browser.
